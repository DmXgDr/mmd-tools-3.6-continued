## 范围说明

前一轮主要验证公开版默认策略和选项分离；本次整理命名、作者、版本及图文说明，并适配内部版本兼容检查，没有重跑全部历史模型，也没有把属性检查当作完整动画播放、物理模拟或渲染验证。窗口截图用于核对界面；此前使用合成动作和音频验证关键帧及条带行为。

Windows 接收层开关已在 GUI 检查；本次没有额外进行资源管理器真实拖拽端到端复测。原有物理创建优化、上游材质/表情/骨骼移植算法在本次公开整理中保持不变，不能据此声称所有模型和插件组合都已验证。
