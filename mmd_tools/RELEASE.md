# MMD Tools v3.0.2

## 新增功能

- VMD 导入增加失败恢复：导入过程中出错时，恢复本批次导入前的动作、NLA、姿态、表情值、相机父级与驱动，以及场景帧率和帧范围。
- 移植 PMX 导出打包贴图支持：开启「复制贴图」后，可导出保存在工程内的基础贴图、球面贴图和非共享 Toon 贴图。按材质实际使用的图像处理，即使原路径相同也不会混淆不同图像，并保留原图像的路径和打包状态。
- 移植物理构建帧处理：在刚体缓存起始帧构建物理，完成或出错后恢复原来的当前帧和子帧。

## 修复与优化

- 修复旧 Action 残留：VMD 整批导入成功后，删除本次替换且已无人使用的旧动作；保留共享、手动保留、资产及链接动作，不清理其他无关动作。
- 修复旧动作及其他场景的动画拉长结束帧：只统计当前场景使用的动画，覆盖骨架、形态键、相机数据、材质和实例集合；NLA 按条带的实际位置、缩放、重复和裁剪计算，跳过静音或未启用的条带，并遵循独奏轨道。
- 统一 VMD 导入的「更新场景设置」与侧栏「设置帧范围」：仅更新场景和刚体缓存的结束帧，保留各自起始帧；实际 60 fps 保持不变，其余帧率设为 30 fps，帧率设置与时间 ×2 开关独立。
- 修复物理构建或清理出错后刚体世界未恢复原启用状态的问题；修复部分旧工程物理关节内部引用失效，保留关节对象、参数、动画、驱动及物理世界顺序。
- 移植物理处理性能优化：加快层级遍历、非碰撞约束生成、批量显隐和刚体世界成员检查；针对 Blender 3.6 适配临时物理数据释放与批量删除。
- 移植 PMX 数据读取校验：遇到负数字符串长度、负数记录数量或截断数据时，终止导入并提示错误，避免继续读取不完整模型。
