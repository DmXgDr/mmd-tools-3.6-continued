# MMD Tools v3.0.2

## 功能更新与修复

- 移植物理构建和清理的异常恢复：发生错误时恢复刚体世界原先的启用状态；物理构建使用刚体缓存起始帧，完成或报错后返回原来的当前帧。
- 移植物理处理性能优化：加快层级遍历、非碰撞约束生成、批量显隐和刚体世界成员检查；为 Blender 3.6 单独适配临时物理数据释放，再批量删除对象。
- 修复部分旧工程物理关节的失效内部引用；刷新时保留关节对象、参数、动画、驱动和物理世界顺序。
- VMD 导入增加失败恢复：导入过程中出错时恢复本批次导入前的动作、NLA、姿态、表情值、相机父级和驱动，以及场景帧率与范围；只有整批成功后才删除被替换且无人使用的旧 Action。音频失败仍只跳过音频。
- 结束帧只统计当前场景使用的动画，包括骨架、形态键、相机数据、材质及实例集合中的动画；NLA 按条带在场景中的实际位置、缩放、重复和裁剪计算，跳过静音或未启用的条带，遵循独奏轨道。其他场景和未使用的 Action 不再延长当前场景。
- 统一「更新场景设置」与侧栏「设置帧范围」：只更新场景和刚体缓存的结束帧，保留各自起始帧；实际 60 fps 保持不变，其余帧率设为 30 fps。
- 移植 PMX 导出打包贴图支持：开启「复制贴图」后，从材质实际引用的图像中写出工程内打包的图片，支持基础贴图、球面贴图和非共享 Toon 贴图；不同图像即使原路径相同也分别处理，不修改原图像的路径或打包状态。
- 移植 PMX 数据读取校验：遇到负数字符串长度、负数记录数量或截断数据时终止导入并提示错误，避免把不完整模型当作正常模型继续导入。
