# 更新记录

## 3.0.1 · 2026-11-02

### 新增功能

- 新增「修正翻倍后的骨骼突变间隔」和「修正翻倍后的表情突变间隔」。开启时间 ×2 后，可分别修正持续的骨骼或表情跳变，支持逐帧烘焙数据的保守检测；两项默认关闭。
- 选择 `MMD_Camera` 空物体导入镜头动作时，自动转选其下唯一的实际 `Camera` 并导入。支持同时选择多套镜头；相机缺失或存在多个候选时提示选择具体相机。

### 修复问题

- 修复人物动作导入窗口显示镜头修正的问题。角色根空物体、骨架、表情控制器和镜头分别显示适用选项，隐藏选项不会跨目标执行；关闭时间 ×2 后隐藏并停止三项间隔修正。
- 修复连续三帧、四帧等镜头关键帧组被全部当成切镜的问题。按实际跳变区分切镜与前后运动，仅移动切镜后一帧，保留其他关键帧及其正常翻倍时间。
- 修复选错 VMD、空文件或完全不匹配的动作可能清理角色旧动画的问题；没有导入匹配动画时，不调整工程帧率、帧范围或音频。
- 修复未匹配到骨骼或表情名称时，用空动画覆盖原动作或生成空 NLA 条带的问题。
- 修复向相机或灯光导入不含对应动画的数据时，仍转换对象、修改层级的问题。
- 修复角色与镜头混合批量导入时的处理顺序：每个角色在遇到首个匹配动作时清理一次旧动画；自动匹配音频只参考成功导入到角色的动作文件。
- 修复相机父子对象同时选中时重复导入的问题；直接选中具体 Camera 时，动画写入该相机。
- 修复 Blender 3.6 中 `LIGHT` 类型未正确进入 VMD 灯光导入分支的问题。

## 3.0.0 · 2026-10-25

基于 MMD Tools 2.10.3，面向 Blender 3.6 的首个续更发行版。

发布标题：**MMD Tools 3.6 非官方续更版——高版本功能移植与个人定制**。

### 高版本功能移植

- 六项默认操作预设。
- 骨骼名称检查修复及额外字符替换后的重名处理。
- 附加旋转约束修复。
- 按贴图合并材质。
- 表情滑块日文/英文名称显示，以及全部表情批量插帧。
- 参考高版本拖放交互，提供 Windows / Blender 3.6 的接收适配。

### 个人定制与修复

- Blender 3.6 VPD 姿态库兼容修复，恢复姿态导入、活动/全部姿态导出及姿态库转骨骼表情；保留已有动作。

- 在线更新连接本续更版 GitHub Releases，增加安装包校验、旧版备份和失败恢复。

- VMD 导入动画时间 ×2，默认按当前工程实际帧率判断是否勾选。
- 可选的镜头切换间隔修正、角色旧动画清理、同目录动作音频导入。
- 音频默认新增到空闲音轨，替换原有声音需单独勾选。
- 物理对象导入提速、部分 VMD 导出冗余帧修复和动作清理稳定性处理。
- 预设选择与内容备份、拖放参数会话记忆、拖放开关。

完整使用方法见 [README](README.md)，各项依据见 [来源说明](docs/UPSTREAM.md)。
