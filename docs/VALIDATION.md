# 适用环境与兼容范围

## 适用环境

本版适用于 Blender 3.6，以 MMD Tools 2.10.3 为基础。实际验证环境为 Windows / Blender 3.6.2 + SSGI Native。

拖放导入仅支持 Windows。其他系统可通过文件菜单导入，但本版尚未在其他系统完成验证。

## 功能范围

- 只移植使用教程和来源说明中列出的高版本功能，不等同于完整的高版本 MMD Tools。
- 模型调试只检查和修复骨骼名称，不检查 IK、权重、穿模或物理稳定性。
- 按贴图合并材质依据图像路径和节点条件，不判断完整材质的视觉效果是否相同。
- VMD 时间转换需要由用户确认源动作的时间编排；VMD 本身没有可靠的帧率标记。
- VMD 导出修复针对部分恒定区间的冗余补帧，不会删除表达跳变或插值所必需的关键帧。

不同模型、工程、渲染器和第三方插件组合可能存在差异。使用各项工具时，请按教程核对其适用对象和选项。

具体操作见 [使用教程](../README.md)，移植依据及实现差异见 [来源说明](UPSTREAM.md)。
