# VMD 骨骼与表情突变间隔修正

这是 **Blender 3.6 MMD Tools 续更版独有的新增功能**，不是从高版本 MMD Tools 移植的功能。它用于 VMD 导入时的 30→60 时间转换：尽量找出原动作中的突然切换，避免时间翻倍后多出一帧不需要的中间姿态或表情。

两个修正选项彼此独立，**默认关闭**。它们遵守插件现有的会话记忆和默认操作项预设规则，因此后续打开窗口时，也可能沿用你之前选择或保存的值。

## 在哪里开启

从导入按钮或拖放文件打开 VMD 导入设置，勾选 **「按 30→60 fps 转换动画时间（×2）」** 后，窗口会按当前选中对象显示适用的修正选项。

| 导入前选中的对象 | 显示的新选项 |
| --- | --- |
| 角色根空物体，即模型最上层的 MMD 根节点 | 「修正翻倍后的骨骼突变间隔」和「修正翻倍后的表情突变间隔」 |
| 角色骨架 | 仅「修正翻倍后的骨骼突变间隔」 |
| 表情控制对象 `.placeholder` | 仅「修正翻倍后的表情突变间隔」 |

这里的 `.placeholder` 指 MMD Tools 生成并标记的表情控制对象，不是任意一个同名网格。只选择骨架或 `.placeholder` 时，另一个不适用的修正不会执行，即使预设中保存了开启值。

**原有的统一时间 ×2 选项保持不变。** 新增的两个开关只决定骨骼、表情是否进行额外的间隔修正，不会把动画重复翻倍，也不是两个独立的时间转换开关。关闭时间 ×2 时，新修正选项不显示，也不会执行。

时间 ×2 的初始勾选仍按工程实际帧率及用户预设等现有规则确定。导入前以窗口中的实际勾选状态为准；如果 VMD 已经转换成 60 帧时间，不要再次勾选时间 ×2。

## 怎样使用

1. 先选好导入目标，再打开 VMD 导入设置。
2. 确认这份 VMD 需要执行 30→60 时间转换，勾选时间 ×2。
3. 按需要开启骨骼、表情中的一项或两项。没有明显突变问题时可以保持关闭。
4. 确认导入后，查看原本发生切换的位置，重点检查切换前后几帧。

如果身体动作和表情是 **两份 VMD**，建议按以下顺序导入：

1. 选中角色根空物体，导入身体动作；需要时开启骨骼突变间隔修正。
2. 选中该角色的 `.placeholder`，再导入表情；需要时开启表情突变间隔修正。

这样第二份 VMD 只会交给表情控制对象，不会因为文件里夹带少量骨骼帧而覆盖刚导入的身体动作。没有 `.placeholder` 时，先按插件原有的变形绑定流程建立表情控制对象。

## 它怎样改变帧的位置

修正会把识别到的突变中，**后一个关键帧从翻倍后的时间前移 1 帧**，并同步移动该关键帧的曲线手柄。骨骼按完整变换通道一起处理；表情只处理对应的表情权重通道，不会把同一时间的其他表情一起移动。

例如，源 VMD 在第 119、120 帧之间突然切换，导入边距设为 0：

| 阶段 | 切换前关键帧 | 切换后关键帧 |
| --- | --- | --- |
| 源 VMD | 119 | 120 |
| 导入到 Blender，尚未翻倍 | 120 | 121 |
| 时间 ×2 后 | 240 | 242 |
| 检出突变并修正后 | 240 | 241 |

表中导入时多出的 1 帧来自原有的 VMD 导入起点规则。修正后，第 241 帧直接进入后一个姿态或表情，不再保留原本位于 240、242 之间的那一帧过渡。

**并非所有翻倍后相差 2 帧的关键帧都会移动。** 对正常的连续运动，中间帧是有效的插值画面，应当保留。

## 检测范围与限制

检测主要寻找“前后有一段相对稳定或缓慢变化的轨迹，中间突然跳到另一段轨迹，并保持下来”的情况。骨骼使用位置变化和实际旋转角判断，四元数的正负号等价表示不会被直接当成姿态跳变。

它尽量跳过连续渐变、连续高速运动，以及很快恢复原状的短暂尖峰。短暂眨眼、普通口型过渡通常属于这些情况，但检测不理解表情名称或作者意图，因此仍有边界：

- 持续较久的闭眼、长时间保持的口型，也可能表现为持续阶跃，被当成需要修正的表情切换。
- 逐帧烘焙动作可以参与检测，但物理弹跳、IK 或约束造成的持续突变，也可能与人为切换相似。
- 变化幅度较小、缺少前后上下文，或者位于动作开头、结尾附近的切换，可能不会被识别。
- 只有在 Blender 中经过父级、约束、IK 或物理计算后才产生，而没有体现在 VMD 关键帧里的跳变，无法靠这项原始数据检测可靠判断。

因此，它是一个**保守的辅助修正选项**，不能保证所有切换都检出，也不能保证完全没有误判。导入后应检查切换附近的结果；不合适时关闭对应选项重新导入，或自行调整该处关键帧。

## 哪些内容不会改变

这两个选项仅作用于本次新导入的动画时间，不修改源 VMD，也不改变导出流程。它们不会删除关键帧，不做关键帧精简、动作平滑或原始抖动清理，不修改骨骼关键帧的姿态值、表情权重值，也不会解除表情驱动器绑定。

检测直接分析 VMD 轨道，不会为此逐帧播放时间线、计算物理或更新整套模型。关闭对应选项时，跳过该类检测；同一次导入需要应用到多个目标时，已分析的源轨道会复用检测结果。
